١ ملخص العرض

تطوير منصة تعليمية إلكترونية متكاملة للسوق الكويتي، تجمع للطالب في مكان واحد: المذكرات الدراسية، فيديوهات الشرح، الاختبارات الإلكترونية المصححة تلقائيًا، تقارير الأداء، ونظام اشتراكات مدفوعة عبر بوابة دفع كويتية — مع لوحة متابعة لولي الأمر ولوحة تحكم شاملة للإدارة. المنصة موقع ويب Responsive يعمل من المتصفح على الموبايل والتابلت والكمبيوتر، بواجهة عربية كاملة (RTL) وهوية بصرية خاصة بالمشروع.

٢ نطاق العمل — ما سيتم تسليمه

أولًا: تجربة الطالب

  1. حساب شخصي: تسجيل ودخول آمن + استعادة كلمة المرور، مع تحديد المرحلة والصف الدراسي.
  2. تصفح المنهج: تنظيم كامل حسب نظام الكويت: المرحلة (ابتدائي / متوسط / ثانوي) ← الصف ← المادة ← الوحدات والدروس.
  3. المذكرات: عرض ملفات PDF داخل المنصة مع إمكانية التحميل.
  4. فيديوهات الشرح: مشغل فيديو منظم بالدروس، يعمل بسلاسة على الموبايل والكمبيوتر.
  5. الاختبارات الإلكترونية: اختبارات موقوتة بأسئلة اختيار من متعدد وصح/خطأ، مع تصحيح تلقائي فوري عند التسليم.
  6. تقارير الأداء: صفحة نتائج توضح الدرجات، نسبة الإنجاز، ونقاط القوة والضعف لكل مادة ودرس.
  7. إدارة الاشتراك: صفحة توضح الباقة الحالية، تاريخ الانتهاء، وخيارات التجديد والترقية.

ثانيًا: تجربة ولي الأمر

  1. حساب ولي أمر مرتبط بحساب الطالب (أو أكثر من طالب).
  2. لوحة متابعة: درجات الابن، مستوى تقدمه في المواد، ونتائج اختباراته.

ثالثًا: لوحة تحكم الإدارة (Admin)

  1. إدارة الهيكل الدراسي: إضافة وتعديل المراحل والصفوف والمواد والدروس.
  2. إدارة المحتوى: رفع المذكرات والفيديوهات وتنظيمها بالدروس — دون الحاجة للمطوّر.
  3. بنك الأسئلة: إضافة وتصنيف الأسئلة وإنشاء الاختبارات وربطها بالدروس.
  4. إدارة المستخدمين: الطلاب وأولياء الأمور، تفعيل/إيقاف الحسابات.
  5. إدارة الباقات: إنشاء باقات (مادة واحدة / مرحلة كاملة)، التسعير، وأكواد الخصم.
  6. متابعة المبيعات: سجل المدفوعات والاشتراكات النشطة والمنتهية.

رابعًا: الأنظمة المساندة

  1. الدفع الإلكتروني: ربط مع بوابة كويتية (Tap Payments أو MyFatoorah) — دعم KNET و Visa / Mastercard.
  2. الإشعارات: إشعارات داخل المنصة + بريد إلكتروني عند نجاح الدفع، اقتراب انتهاء الاشتراك، وصدور النتائج.
  3. حماية المحتوى: تقييد الوصول للمذكرات والفيديوهات على المشتركين فقط، وحماية الحسابات والبيانات.
  4. التصميم: واجهة عربية عصرية بهوية المشروع البصرية (اسم + لوجو + ألوان).

٤ مراحل التنفيذ ونقاط المعاينة

كل مرحلة تنتهي بمعاينة يستلمها العميل للمراجعة قبل الانتقال للمرحلة التالية.

المرحلةنطاق العملما يعاينه العميل
1 التأسيس: بنية المشروع + قاعدة البيانات + نظام الحسابات والأدوار تسجيل ودخول فعلي على رابط تجريبي
2 الهيكل الدراسي + لوحة الأدمن + رفع المذكرات والفيديوهات رفع محتوى تجريبي من لوحة الأدمن وعرضه للطالب
3 بنك الأسئلة + الاختبارات + التصحيح التلقائي + التقارير أداء اختبار تجريبي كامل واستلام النتيجة
4 الباقات والاشتراكات + بوابة الدفع الكويتية + أكواد الخصم عملية شراء تجريبية كاملة ببوابة الدفع
5 لوحة ولي الأمر + الإشعارات + الهوية البصرية النهائية نسخة شبه نهائية للمنصة كاملة للمراجعة
6 الإطلاق والتسليم: نقل المنصة على استضافة العميل + تدريب على الأدمن + تسليم الكود المصدري المنصة تعمل على نطاق العميل + جلسة تدريب
مدة التنفيذ تتحدد بعد اعتماد الخطة، وتعتمد جزئيًا على سرعة توفير العميل للمحتوى التجريبي وبيانات بوابة الدفع والاعتمادات المرحلية.

٦ التزامات العميل

  • توفير اسم المشروع وهويته البصرية (أو تفويض المطوّر باقتراحها).
  • توفير سجل تجاري / نشاط مسجل — مطلوب لتفعيل بوابة الدفع الكويتية (KNET).
  • توفير عينة من المحتوى في بداية العمل (مذكرة + فيديو + مجموعة أسئلة) لبناء النظام عليها.
  • فتح حسابات الخدمات الخارجية باسمه (استضافة، بوابة دفع، بريد) مع منح المطوّر صلاحية الإعداد.
  • مراجعة معاينات المراحل والرد عليها في وقت معقول.
